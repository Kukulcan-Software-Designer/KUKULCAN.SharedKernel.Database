# Support

`KUKULCAN.SharedKernel.Database` provides shared EF Core persistence infrastructure.

## Before Asking for Help

Check `README.md`, `API_GUIDELINES.md`, `CHANGELOG.md` and existing issues/discussions first.

For bugs, provide the package version, .NET version, EF Core version, provider, operating system, exception, stack trace and a minimal reproduction where possible.

## Reporting Bugs

Use GitHub Issues for reproducible defects in this package.

## Architectural Questions

Use GitHub Discussions for questions about `KukulcanDbContextBase`, interceptors, tenant filtering, soft delete, unit of work, transactions, provider configuration or integration with `KUKULCAN.SharedKernel`.

## Feature Requests

Explain the repeated cross-module problem and why it belongs in shared persistence infrastructure.

## Out of Scope

General C# programming, SQL administration, unrelated EF Core support, IDE configuration and application-specific business logic are outside this project's support scope.

## Security

Security vulnerabilities must follow `SECURITY.md`, not public issues.
